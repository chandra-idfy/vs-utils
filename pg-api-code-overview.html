Profile Gateway API — Onboarding Guide

Profile Gateway API is a KYC/identity-verification gateway built on Elixir/Phoenix. It coordinates profile creation, capture artifacts, verification tasks, and external provider calls. Backed by Postgres (Ecto), Redis, and RabbitMQ.

  • Languages: Elixir, JSON, YAML, Shell, Dockerfile
  • Core frameworks: Phoenix, Phoenix Ecto, Phoenix PubSub, Plug Cowboy, Distillery
  • Notable libs: AppSignal, Goth + Google API Storage, HTTPoison/Finch/Hackney, Canary (authz), CorsPlug, Libcluster, JOSE, Redix, ExSM (state machines), Gettext, logger_json
  • Static analysis & testing: Sobelow, Credo, ExCoveralls, Bypass
  • Ship pipeline: Docker + GitLab CI
  • Analyzed at: 2026-04-30 (commit 5b387331b)

Key Concepts

  • Profile is the central aggregate. A Profile represents one customer's KYC journey from creation through completion. The data model is Profile → Task → Capture → Artifact.
  • Packages are a JSONC DSL. Tenants configure flows declaratively (see docs/package/PACKAGE.md); parser.ex compiles them into in-memory structures that drive Task creation.
  • State machines are explicit. Both Profile and Task lifecycles are governed by ExSM-driven state machines (profile_state_machine.ex, task_state_machine.ex) that fire side effects (notifications, webhooks, transitions).
  • Rule engine + rule workflows. rule_engine.ex recursively evaluates AND/OR/==/!= boolean expressions over task/artifact/profile data; rule_workflow_engine.ex runs configured workflows for risk, propensity, and decision-making.
  • Multi-tenant via OrganizationUnit. OU is the tenant aggregate (x-idfy-ou-id header → cust.ex plug → OrganizationUnit).
  • Authorization is policy-based. abilities.ex implements Canada.Can for User, used via Canary plugs across all controllers.
  • Encryption is built into the Repo. repo.ex transparently encrypts/decrypts sensitive structs (Profile, Artifact, Task, Snapshot) with per-OU keys via payload_encryption.ex (KeyStore + DEK rotation).
  • Realtime is first-class. Mobile/web clients hold long-lived WebSockets via profile_socket.ex, capture_socket.ex, agent_socket.ex. Channels broadcast state changes.
  • Async work goes through RabbitMQ + Redis. Profile transitions, webhook delivery, purges, and long-running provider calls are decoupled via consumers/publishers.

File Map (by Layer)

HTTP Boundary — lib/kyc_gateway_backend_web/

  • endpoint.ex — Phoenix Endpoint: agent/capture/dashboard sockets, CORS, parsers, session cookie, plug pipeline.
  • router.ex — 22 named pipelines routing /ext (customer/dashboard/agent/workflow) and /int (admin/cron) APIs.
  • controllers/profile_controller.ex — Mega-controller: index, create_sync/async, invite, show, cancel, recapture, submit_review, bulk_submit_review, notes, purge, config.
  • controllers/task_controller.ex — Central Task controller: response callbacks from API Gateway, Truesight, AssistedVKYC, SelfVideo, ConsentGateway, DocumentFetcher, IDfy360.
  • controllers/capture_controller.ex — Capture-session HTTP entrypoints (status, config, redirect-URL validation, create/expire/submit_error).
  • controllers/organization_unit_controller.ex — OU/tenant management: config, encryption-key rotation, storage auth, logo upload.
  • controllers/package_controller.ex — Package definitions CRUD + version history, validate, update_task_configs, create-profile form schema.
  • controllers/utv_task_controller.ex — UTV (un-traceable video) dashboard endpoints with parallel data fetches via Task.async.
  • channels/session_channel.ex — Primary capture/task session lifecycle channel — 30+ message handlers (session start/end, fetch_config, update_response, liveness, GPS, page transitions).
  • channels/artifact_channel.ex — Artifact lifecycle (update, fetch, fetch_document, initiate_div, initiate_check) for both task and capture sockets.
  • channels/notification_channel.ex — Reviewer/operator real-time notifications, Presence tracking, work-item broadcasts.
  • plug/cust.ex — Resolves OU from x-idfy-ou-id header, authorizes incoming /cust requests.
  • views/profile_view.ex — Central JSON view: 20+ payload variants (dashboard, status, review, capture, scheduling, recapture, undo).

Domain Contexts — lib/kyc_gateway_backend/

  • profiles/profile_state_machine.ex — ExSM machine: pending → in-progress → captured → completed → approved/rejected/review with side effects.
  • profiles/profile_workflow.ex — Evaluates datapoints (rules, decisions, priorities) to decide a profile's next step.
  • profiles/profile_search.ex — Composable Ecto query builder (reference_id, status, OU, dates, package, reviewer, profile-tag, capture-data).

  • profiles/request_parser.ex — Largest parser in the system: validates Profile-create requests against the Package definition.
  • packages.ex — Packages context: CRUD, validation, feature flags, capture/review/risk derivation.
  • packages/parser.ex — Master parser orchestrator for KYC package JSON, dispatching to specialized parsers (capture, review, AVKYC, SVKYC, video, risk, propensity, decision).
  • tasks.ex — Tasks context: lifecycle, retries, state transitions, factory, template binding, queries, webhooks.
  • tasks/task_state_machine.ex — ExSM: queued → in_progress → processing → saved → completed/failed/cancelled.
  • tasks/task_workflow_engine.ex — Executes rule-based workflow actions: initiate, complete, fail, deprecate, clear, copy.
  • captures.ex — Capture session lifecycle, recapture, session/auth tokens, status transitions.
  • artifacts.ex — CRUD, query, lifecycle over uploaded artifacts (images, PDFs, reports, recordings).
  • accounts.ex — Public API for OUs, users, themes, account-level configurations.
  • authorization.ex — Role/permission CRUD and access decisions.
  • risk_engine/risk_engine_core.ex — Risk evaluation orchestrator: stages, rule workflows, results.
  • rule_engine.ex — Recursive boolean expression evaluator (AND/OR/==/!=) over task/artifact/profile sources.
  • rule_workflows/rule_workflow_engine.ex — Single/multi-mode workflow evaluation aggregating per-workflow results.
  • snapshots/save_attempt_snapshot.ex — 1093-line snapshot writer capturing comprehensive profile-attempt state.
